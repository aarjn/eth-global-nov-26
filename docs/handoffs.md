## W4 -> W2 / W3 / coordinator (Arkiv store ready) — 08:30 IST
- `createArkivStore(process.env)` from `@paisalink/arkiv` implements `PaisaStore` on Arkiv Rabdi. Writes need `ARKIV_PRIVATE_KEY` **and** `ARKIV_ACCESS_KEY` (writes without a key are refused unless `ARKIV_ALLOW_ANON_WRITES=1`, to avoid the 429 lockout). Reads work without a key.
- **W2:** `recordPayment(p)` also patches the invoice to `state: "paid"` + `pay_tx` **in the same Arkiv transaction** if the invoice is still `open`, so you don't need a separate `upsertInvoice` for the paid transition (doing it anyway is a free no-op: unchanged upserts send no tx). Refunds: `upsertInvoice({...inv, state: "refunded"})` and `recordPayment({...p, refundTx})`. All writes are serialized in one queue (one writer nonce); each write takes about one block (~2 s) plus the receipt.
- **W2 extras on the store** (not in `PaisaStore`, duck-type them): `store.health()` → `{chainId, block, writer, writerBalanceWei, accessKey: boolean, canWrite, rateLimit}` for `GET /health`; `store.writes` (every write with `explorerUrl` + `txHash`); `store.onWrite = (w) => ...` hook; `store.getMerchantByHandle(handle)`. An Arkiv 429 throws `ArkivRateLimitedError` (name check: `err.name === "ArkivRateLimitedError"`).
- `amountUsdt` comes back from Arkiv in canonical decimal form (`"49.50"` → `"49.5"`); format for display in the UI.
- **W3:** `apps/api/src/routes/merchants.ts` serves `POST /merchants` (201 new / 200 existing; keeps `verified`, `gasUsedWei`, `createdAt`; 409 `HANDLE_TAKEN`), `GET /merchants/:wallet` (404 `MERCHANT_NOT_FOUND`), `GET /merchants/:wallet/invoices[?state=open]` (newest first), `GET /merchants/:wallet/payments`. Handles: 3–32 chars `a-z 0-9 . _ -`, start/end alphanumeric, lowercased (matches your form). Merchant responses may carry an extra `arkivUrl` (Rabdi explorer link of the entity) — nice for a "View on Arkiv" link. Arkiv failures → 503 `ARKIV_UNAVAILABLE` / 429 `ARKIV_RATE_LIMITED`.
- **Coordinator/S3:** README query line: `bun run scripts/query.ts [merchantAddress]` (works on a clean clone after `bun install`, no env needed). Schema draft at `arkiv/schema.md`. `packages/arkiv` has devDeps `typescript@7.0.2` + `@types/bun@1.4.3` for `bun run typecheck`.
